About this course

The Data Analysis programme teaches you how to collect, prepare, analyse and present data so that it can support real decisions. Often searched for as data analytics training in Lagos, this 18-week course takes you from spreadsheets and data preparation to database querying with SQL, Python programming, and visual reporting in Power BI and Tableau.

Every stage uses practical exercises and business case studies, so you practise applying each tool to realistic problems instead of only learning its features. The programme is suitable for beginners as well as professionals and business owners who want to add data skills.

What you will learn

  • How to enter, clean and prepare data in Microsoft Excel and Google Sheets
  • How to summarise and present findings with formulas, PivotTables and charts
  • How to retrieve and combine data from databases using SQL
  • How to write Python programs to analyse and explore data
  • How to build interactive dashboards and reports in Power BI
  • How to create visualisations and dashboards in Tableau
  • How to turn analysis into clear reports that support business decisions

Curriculum and learning modules

The programme runs for 18 weeks. Modules follow a logical sequence, and the weekly breakdown below shows how the topics are organised.

  1. Weeks 1–3

    Microsoft Excel

    • Data entry, formatting and organisation
    • Formulas and functions
    • Cleaning and preparing data
    • Sorting, filtering and PivotTables
    • Charts and simple dashboards
  2. Weeks 4–5

    Google Sheets

    • Functions and data preparation in Sheets
    • Data validation and importing data
    • Sharing and collaborating on analysis
  3. Weeks 6–8

    SQL for data analysis

    • Databases, tables and how data is organised
    • Selecting, filtering and sorting data
    • Aggregating data and grouping results
    • Combining tables with joins
  4. Weeks 9–12

    Python programming for data analysis

    • Python fundamentals: variables, data types, conditions, loops and functions
    • Reading data from files
    • Cleaning, exploring and summarising data
    • Simple visualisations
  5. Weeks 13–15

    Power BI

    • Importing and transforming data
    • Relationships and data modelling
    • Calculations and measures
    • Building interactive reports and dashboards
  6. Weeks 16–17

    Tableau

    • Connecting to data sources
    • Building charts and visualisations
    • Creating dashboards and telling a story with data
  7. Week 18

    Capstone project and reporting

    • Defining a business question
    • Preparing, analysing and visualising the data
    • Presenting findings in a clear report

Tools and technologies

Practical exercises and projects

Learning is hands-on. You practise each topic through guided exercises and assignments, and apply what you learn in real-world style projects.

  • Weekly hands-on exercises in each tool
  • Business case studies, for example sales, customer or survey data
  • An interactive dashboard built in Power BI
  • A dashboard and visual story built in Tableau
  • A capstone project and report that applies the full toolkit

Learning objectives and expected competencies

By the end of the course, you should be able to:

  • Clean and prepare data for analysis
  • Query databases with SQL
  • Use Python to explore and analyse data
  • Build dashboards and reports in Power BI and Tableau
  • Communicate data findings clearly to non-technical audiences

Career and business applications

The skills in this course can be applied in several ways, including:

  • Reporting and performance tracking in businesses and organisations
  • Using sales, operations, marketing or customer data to support decisions
  • Data-related tasks such as preparing, analysing and presenting data
  • Business owners tracking and understanding their own data
  • Freelance or project-based data work

We support our learners beyond the classroom through career guidance, CV and LinkedIn optimisation, mentorship, and access to relevant internship and employment opportunities where available. While employment is not guaranteed, we help learners prepare for available opportunities.
