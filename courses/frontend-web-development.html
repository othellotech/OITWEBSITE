About this course

Coding / Frontend Web Development teaches you how websites are built, styled and made interactive. Over 10 weeks you progress from website structure with HTML to styling with CSS, responsive layouts that work on any screen, and interactivity with JavaScript.

The course is built around practical website projects, so you finish with real work that shows what you can do. It suits beginners, students, career changers and anyone who wants to start web development training in Lagos.

What you will learn

  • How the web works and how websites are put together
  • How to structure web pages with HTML
  • How to style pages with CSS, including colours, typography and layouts
  • How to make websites responsive for phones, tablets and computers
  • The fundamentals of JavaScript
  • How to write JavaScript functions and use them to add interactivity
  • How to plan, build and present complete website projects

Curriculum and learning modules

The programme runs for 10 weeks. Modules follow a logical sequence, and the weekly breakdown below shows how the topics are organised.

  1. Week 1

    Introduction to web development

    • How websites and browsers work
    • The tools you will use, including a code editor and browser developer tools
    • Planning a simple website
  2. Weeks 2–3

    HTML

    • Page structure, headings, text, links and images
    • Lists, tables and forms
    • Organising content with semantic layout
  3. Weeks 4–5

    CSS

    • Selectors, colours, typography and spacing
    • Page layout with Flexbox and Grid
    • Styling navigation, cards and forms
  4. Week 6

    Responsive web design

    • Designing for different screen sizes
    • Media queries and flexible layouts
    • Testing a site on phone, tablet and desktop
  5. Weeks 7–8

    JavaScript fundamentals

    • Variables, data types and operators
    • Conditions and loops
    • Arrays and objects
  6. Week 9

    JavaScript functions and practical applications

    • Writing and using functions
    • Responding to clicks and form input
    • Building small interactive features
  7. Week 10

    Website development project

    • Planning, building and testing a complete responsive website
    • Presenting your finished project

Tools and technologies

  • HTML
  • CSS
  • JavaScript
  • Code editor
  • Browser developer tools

Practical exercises and projects

Learning is hands-on. You practise each topic through guided exercises and assignments, and apply what you learn in real-world style projects.

  • A responsive personal or portfolio website
  • A styled, mobile-friendly landing page
  • Interactive features built with JavaScript
  • A final website development project

Learning objectives and expected competencies

By the end of the course, you should be able to:

  • Build well-structured web pages with HTML
  • Style and lay out pages professionally with CSS
  • Create responsive websites that work on any device
  • Add interactivity with JavaScript
  • Plan and complete a website project from start to finish

Career and business applications

The skills in this course can be applied in several ways, including:

  • Building websites for small businesses, organisations or personal brands
  • Creating a personal portfolio website
  • Freelance or project-based website work
  • A foundation for further study, such as our Full Stack Web Development course

We support our learners beyond the classroom through career guidance, CV and LinkedIn optimisation, mentorship, and access to relevant internship and employment opportunities where available. While employment is not guaranteed, we help learners prepare for available opportunities.
