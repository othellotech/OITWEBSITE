About this course

Coding / Full Stack Web Development builds on frontend development and takes you into backend development and database management. Over 18 weeks you learn to build complete web applications, from the pages users see to the server and database behind them.

The backend is taught through one of two pathways: Python with Django, or Node.js with MongoDB. These are alternative pathways, and learners follow one of them. Ask us on WhatsApp which pathway the next cohort will follow.

What you will learn

  • HTML, CSS and JavaScript for building the frontend
  • Frontend development concepts and how a browser talks to a server
  • Backend development fundamentals through one pathway: Python with Django, or Node.js with MongoDB
  • Database management and working with application data
  • How to connect the frontend and backend into one working application
  • How to plan and complete a practical full-stack project

Curriculum and learning modules

The programme runs for 18 weeks. Modules follow a logical sequence, and the weekly breakdown below shows how the topics are organised.

  1. Weeks 1–5

    Frontend foundations

    • HTML and page structure
    • CSS and responsive design
    • JavaScript fundamentals and interactivity
  2. Week 6

    Frontend development concepts

    • Organising a frontend project
    • How the browser sends requests to a server and receives responses
  3. Weeks 7–10

    Backend development fundamentals (one pathway)

    • Setting up a backend project and handling requests
    • Routes, logic and responses

    Pathway A: Python with Django

    • Python for backend development
    • Django project structure
    • Views, templates and routing

    Pathway B: Node.js with MongoDB

    • Node.js fundamentals
    • Building a server and routes
    • Handling requests and responses
  4. Weeks 11–13

    Database management

    • Designing and organising data
    • Creating, reading, updating and deleting records

    Pathway A: Django

    • Models and a relational database
    • Querying and managing data

    Pathway B: MongoDB

    • Collections and documents
    • Querying and managing data
  5. Weeks 14–15

    Application development and integration

    • Connecting the frontend to the backend
    • Handling forms and user input
    • Testing and improving the application
  6. Weeks 16–18

    Full-stack capstone project

    • Planning and building a complete application
    • Presenting your finished project

Backend pathways: Python with Django or Node.js with MongoDB. They are alternatives, and learners follow one pathway.

Tools and technologies

  • HTML
  • CSS
  • JavaScript
  • Python with Django (backend pathway)
  • Node.js with MongoDB (backend pathway)
  • Database management

Practical exercises and projects

Learning is hands-on. You practise each topic through guided exercises and assignments, and apply what you learn in real-world style projects.

  • Frontend pages built from scratch
  • A backend with routes connected to a database
  • A practical full-stack application, for example a records, booking or inventory-style app
  • A capstone project that joins the frontend, backend and database

Learning objectives and expected competencies

By the end of the course, you should be able to:

  • Build responsive frontends with HTML, CSS and JavaScript
  • Develop backend logic through your chosen pathway
  • Design and manage application data
  • Integrate a frontend and backend into a working application
  • Plan, build and present a full-stack project

Career and business applications

The skills in this course can be applied in several ways, including:

  • Building web applications for businesses and organisations
  • Creating complete projects for a professional portfolio
  • Freelance or project-based web development work
  • A foundation for continued learning in software development

We support our learners beyond the classroom through career guidance, CV and LinkedIn optimisation, mentorship, and access to relevant internship and employment opportunities where available. While employment is not guaranteed, we help learners prepare for available opportunities.

Frequently asked questions

Do I have to learn both Django and Node.js?

No. They are alternative backend pathways: Python with Django, or Node.js with MongoDB. Learners follow one of them.

Does the course include frontend development?

Yes. The programme builds on HTML, CSS and JavaScript before moving into the backend and databases.

How long is the course?

The course runs for 18 weeks.

Can I study online?

Yes. Classes are hybrid, so you can study online, in person at our centre in Ojo, or both.
